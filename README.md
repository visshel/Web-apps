# Mercedes-AMG F1 — Лабораторная работа №3

## Структура проекта

```text
Mercedes_AMG_F1_Lab3/
├── node_modules/             # появляется после npm install
├── .gitignore
├── package-lock.json
├── package.json
├── pages/
│   ├── main/
│   │   └── index.js           # навигация, калькулятор, таймер и стратегия
│   └── product/
│       └── index.js           # загрузка, фильтрация и действия с коллекцией
├── components/
│   ├── product-card/
│   │   └── index.js           # создание и отображение карточек
│   ├── product/
│   │   └── index.js           # подробная карточка и уведомление
│   └── back-button/
│       └── index.js           # кнопки возврата
├── index.html
├── main.js                    # точка входа модулей браузера
├── server.js                  # локальный Node.js HTTP-сервер и mock API
└── styles.css                 # оформление
```

`node_modules/` не включается в архив: npm создаёт его локально при установке зависимостей. Проект использует встроенные модули Node.js и не требует сторонних пакетов.

## Запуск

1. Установите Node.js версии 18 или новее.
2. Откройте терминал в папке проекта.
3. Выполните `npm install`.
4. Выполните `npm start`.
5. Откройте `http://127.0.0.1:3000`.

## Функции

- переход между разделами сайта;
- калькулятор, таймер круга и расчёт стратегии;
- загрузка mock-коллекции через `GET /api/cars`;
- поиск и фильтрация болидов;
- просмотр подробностей;
- добавление копии первой карточки и удаление карточек;
- всплывающие уведомления.

Изменения коллекции выполняются в памяти браузера и сбрасываются при перезагрузке страницы.
